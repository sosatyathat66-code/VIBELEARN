## 4. Decisions and Assumptions
1. **Monorepo / Workspace Architecture**:
   - `frontend/` and `backend/` are standalone directories capable of independent deployment (Vercel for frontend, Render for backend).
   - Root `package.json` provided with npm workspaces (`"workspaces": ["frontend", "backend"]`) and convenience orchestrator scripts (`npm run dev:frontend`, `npm run dev:backend`, `npm run lint`), preserving standalone operation inside each subfolder.
2. **Frontend Stack (Tasks 1.1, 1.3)**:
   - React 18 / Vite using JSX and standard JavaScript.
   - Tailwind CSS v3 (`tailwindcss`, `postcss`, `autoprefixer`) with `tailwind.config.js` and `postcss.config.js` matching the system design document.
   - Folder structure initialized with `src/{assets,components,pages,hooks,services,utils}`, `App.jsx`, `main.jsx`, `index.css`.
3. **Backend Stack (Task 1.2)**:
   - Node.js with native ES Modules (`"type": "module"`), Express.js, CORS, and dotenv.
   - Health check endpoint at `GET /health` and base API route at `/api`.
   - Folder structure initialized with `src/{config,db,middlewares,routes,controllers,services,repositories}`, `index.js`, and `drizzle.config.js` configuration placeholder for Phase 3.
4. **Code Quality & Tooling (Task 1.4)**:
   - ESLint (flat config `eslint.config.js`) configured for React in `frontend` and Node.js in `backend`.
   - Prettier configured in both workspaces for consistent code style.
5. **Environment Configuration (Task 1.5)**:
   - `frontend/.env.example`: `VITE_CLERK_PUBLISHABLE_KEY`, `VITE_API_URL`.
   - `backend/.env.example`: `PORT`, `NODE_ENV`, `DATABASE_URL`, `CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, `CLIENT_URL`.
   - Proper `.gitignore` files in root, `frontend`, and `backend` ensuring sensitive files (`.env`, `.env.local`) and `node_modules/` are not tracked.

## 8. Acceptance Criteria

3. `npm run dev` in `backend/` launches Express development server on `http://localhost:5000`.
4. `GET http://localhost:5000/health` responds with HTTP 200 `{ "status": "ok", "timestamp": ... }`.
5. `npm run lint` passes in `frontend/` and `backend/` with zero errors.
6. `docs/roadmap.md` items 1.1 to 1.6 marked as complete `[x]`.
